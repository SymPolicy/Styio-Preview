# Styio All-in-One License Policy

**Purpose:** Record the source-license boundary enforced by `styio-audit`.

**Last updated:** 2026-06-29

`Styio-Preview` is an Apache-2.0 source aggregation project for Styio-family repositories. The accepted SPDX identifier is `Apache-2.0`.

Any source-derived compiler, package-manager workflow, Vityo client surface, bundled distribution, or build artifact that redistributes Styio-family source or binaries must preserve the Apache License, Version 2.0 terms, copyright notices, NOTICE content when present, modification notices, and patent-license conditions required by Apache-2.0.

The repository audit gate checks for Apache-2.0 license evidence, matching package metadata where present, and this source-distribution notice before delivery can be considered closed.
